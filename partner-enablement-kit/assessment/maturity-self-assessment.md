# Maturity Self-Assessment

> **Instantiation layer.** This diagnostic is a starting point. Adapt the wording and examples to
> your organization via `brand.yaml`; you may add locally relevant items, provided scoring remains
> consistent with `scoring-and-routing.md`.

This assessment locates an organization on the maturity model (`constitution/02-maturity-model.md`)
and, together with the routing logic, recommends a delivery path. It is designed to be completed
in one working session by an enablement leader, ideally with input from sales leadership, a
technical/SE leader, and — if one exists — L&D.

## How to run it

1. Score each of the twelve statements from **0 to 4** using the scale below.
2. Answer the two **routing questions** at the end (these determine Path A vs Path B, not the
   maturity score).
3. Total the twelve statement scores (maximum 48) and take the result to
   `scoring-and-routing.md`.

**Scoring scale**

| Score | Meaning |
| --- | --- |
| 0 | Not true / does not happen |
| 1 | Rarely true; isolated or ad hoc |
| 2 | Sometimes true; inconsistent across the organization |
| 3 | Mostly true; standard practice with gaps |
| 4 | Consistently true; systematic and measured |

Answer for the organization **as it actually operates today**, not as it aspires to operate.

## Routing questions

These two questions determine **which delivery path** is recommended. They are scored separately
from the twelve statements above.

**R1 — Dedicated learning function.**
Does the organization have a dedicated Learning & Development (or enablement) function with the
capacity to train others?

- [ ] **Yes — established.** A staffed L&D/enablement function exists and can take on
  train-the-trainer responsibility.
- [ ] **Partial.** Some enablement responsibility exists but is part-time, fragmented, or
  embedded in other roles.
- [ ] **No.** There is no dedicated function; enablement, where it happens, is owned by line
  managers or individuals.

**R2 — Field trainer reach.**
Is there an existing population of field trainers, senior sellers, or senior technical staff who
could be enabled first and then cascade enablement to the wider field?

- [ ] **Yes.** A credible train-the-trainer population exists.
- [ ] **Limited.** A few candidates exist but not a reliable population.
- [ ] **No.** Enablement must reach the field directly.

Carry the statement subtotal and both routing answers to `scoring-and-routing.md`.
