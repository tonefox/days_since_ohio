# Session Plan Template

> **Instantiation layer / template.** A reusable skeleton for a single enablement session. Used
> primarily in **Path A (Trainer Cascade)** to structure how trainers deliver and how Advisors
> are taught to teach. Copy this file per session and fill it in.

A session exists to build **capability, not coverage** (Article I). Every section below is here to
keep the session pointed at a demonstrable outcome rather than at content delivery.

## 6. Assessment linkage

How does this session connect to certification? Reference the demonstration built from
`templates/assessment-builder-template.md` for the same competency. A session should *prepare for*
the demonstration, not replace it.

## 7. Train-the-trainer note (Path A, Advisor tier)

When the audience is trainers-in-training, add a layer: after practicing the capability itself,
have them practice **teaching and assessing** it — framing the outcome, modeling, coaching against
the rubric, and scoring consistently. Advisor certification requires demonstrating both the
capability *and* the ability to develop it in others.

---

### Using AI to build the session
At maturity L1+, use AI to draft the flow, scenario framing, and coaching prompts from the
competency definition, then apply human judgment to fit your audience and context. At L2+, AI
tailors the scenario to each participant's role and vertical.
