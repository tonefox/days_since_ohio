# Amendment Queue

> The controlled gate for changing the Constitution. Skills and orchestrators may **enqueue** proposals here. Only Tony approves Class 3 changes. Nothing in this queue edits `CONSTITUTION.md` until approved and recorded in `CHANGELOG.md`.

## Lifecycle
`drafted → quality-checked → (Class 2: tested in Experiment Register) → awaiting Tony → approved/rejected/deferred → if approved: edit Constitution + Changelog → closed`

Every item uses `templates/CONSTITUTIONAL_AMENDMENT.md` and must carry: current rule · proposed change · reason · supporting evidence (labeled) · risks/unintended consequences · test before adoption · reversal plan · affected section · approval status · final decision · changelog entry.

A Quality Check (`contracts/QUALITY_CHECK.md`) is required before any item reaches Tony.
