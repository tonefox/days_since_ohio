# Learning Ledger

> The Learning & Evidence Layer between operational Skills and the Constitution. Skills and orchestrators **append** observations here. They never rewrite the Constitution. Observations mature up the ladder before they can drive change.
>
> **Maturity ladder:** `Noise → Isolated observation → Emerging pattern → Repeated pattern → Highly consequential verified fact`
> **Promotion rule (from `GOVERNANCE.md` §5):** Emerging → Class 1 calibration · Repeated → Class 2 hypothesis + experiment · Highly consequential verified fact → Class 3 amendment proposal.

---

## What to capture
Search performance · role outcomes · interview feedback · recruiter & hiring-manager signals · market observations · consulting-buyer feedback · query performance · scoring calibration · contradictions · repeated patterns · failed assumptions · proposed constitutional amendments (drafted, then moved to the Amendment Queue).

## Entry schema
```
ID:           LL-YYYYMMDD-NN
Date:
Source skill:
Observation:
Evidence label: (Verified / Corroborated / … )
Maturity:     (Noise / Isolated / Emerging / Repeated / Highly-consequential)
Category:     (search / interview / recruiter / market / buyer / query / scoring / contradiction / failed-assumption)
Links:        (related LL IDs, role/prospect, experiment ID)
Proposed action: (none / Class 1 / Class 2 / Class 3 → Amendment Queue)
Status:       (open / matured / actioned / closed)
```

## How an observation moves
1. Logged here as **Isolated** by default.
2. Corroboration from independent entries raises it to **Emerging** then **Repeated**.
3. Only **Repeated** patterns justify a Class 2 hypothesis; only a **Highly consequential verified fact** justifies a Class 3 proposal.
4. A single observation never overrides the Constitution.
